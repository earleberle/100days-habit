✨ 어떤 기능이 있나요?

  • 참여자별 습관 2개 인증 및 사진 첨부
  • 오늘 인증 / 밀린 인증 / 인증 수정·삭제
  • 100일 개인 기록과 주간 전체 현황
  • 주 2회 PASS 기능
  • 시작 마음가짐과 100일 마지막 회고
  • 카카오톡 인증 공유
  • 설치 후 참여자·습관·기간 등을 스프레드시트에서 관리

🚀 설치 순서

1
Google 스프레드시트를 준비합니다.
사용할 스프레드시트 주소의 /d/고유ID/edit 사이 값을 확인해 둡니다.
2
확장 프로그램 → Apps Script를 엽니다.
배포용 Code.gs 전체 내용을 기존 Code.gs에 붙여넣습니다.
3
Apps Script에서 HTML 파일을 새로 만들고 이름을 index로 지정한 뒤, 배포용 index.html 내용을 붙여넣습니다.
4
프로젝트 설정 → 스크립트 속성에 SPREADSHEET_ID를 추가하고 값에 앞서 확인한 스프레드시트 고유 ID를 입력합니다.
5
실행 함수에서 prepareDeploymentSettings를 선택해 최초 1회 실행합니다. Google 권한 요청이 나오면 승인합니다.
6
스프레드시트의 설정 탭에서 시작일·종료일·참여자·습관 등을 입력합니다.
7
Apps Script에서 배포 → 새 배포 → 웹 앱으로 배포하고 생성된 /exec 주소를 휴대폰에서 테스트합니다.

⚙️ 설치 후에는 어디서 관리하나요?

일상적인 운영은 코드를 수정하기보다 스프레드시트의 설정 탭에서 관리합니다.

  • B2 — 챌린지 시작일
  • D2 — 챌린지 종료일
  • A열 — 참여자 이름
  • B:C열 — 습관 1 / 습관 2
  • D열 — 참여자 사용 여부
  • F:G 설정 영역 — 앱 이름, 카카오 JavaScript 키, 공유 URL, 사진 폴더명, 카카오 공유 사용 여부
💡 참여자나 습관을 추가하는 정도의 변경은 보통 코드를 다시 수정할 필요가 없습니다.

💬 카카오톡 공유 설정

카카오 인증 공유를 사용하려면 Kakao Developers에서 별도의 앱 설정이 필요합니다.

  1. Kakao Developers 애플리케이션을 만들고 JavaScript 키를 확인합니다.
  2. JavaScript SDK 도메인에 https://script.google.com을 등록합니다.
  3. JavaScript 키를 스프레드시트 설정 영역에 입력합니다.
  4. 웹앱에서 인증 후 카카오 공유를 테스트합니다.
4019 오류가 난다면?
Apps Script 화면이 실제로 실행되는 ...script.googleusercontent.com iframe 도메인도 Kakao Developers의 JavaScript SDK 도메인에 등록해야 할 수 있습니다. 자세한 확인 방법은 설명서를 참고하세요.

⚠️ 관리할 때 이것만 주의하세요

  • 이미 인증 기록이 있는 참여자의 이름을 변경하면 과거 데이터와 연결이 끊길 수 있습니다. 관련 기록 시트의 이름도 함께 맞춰주세요.
  • 원본 스프레드시트는 관리자만 편집하고, 참여자에게는 웹앱 링크만 공유하는 것을 권장합니다.
  • 큰 변경 전에는 스프레드시트를 복사해 백업해 두는 것이 안전합니다.
  • 코드 자체를 변경한 경우에는 웹앱을 새 버전으로 다시 배포해야 반영될 수 있습니다.
